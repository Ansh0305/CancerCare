# 🎗 Cancer Awareness & Support – Web Application

A responsive **Cancer Awareness & Support website** built using **React + Tailwind CSS**.  
This project spreads awareness about cancer, highlights the importance of early detection, and provides a simple contact interface for support.

## 📌 Features

- 🎗 General Cancer Awareness theme
- 🖼 Landing section with banner & awareness message
- 📄 Awareness & Support sections
- 📬 Contact form (Name, Email, Message) – frontend only
- 📱 Fully responsive UI
- 🍔 Hamburger menu for mobile
- ✨ Smooth scroll & fade animations

---

## 🛠 Tech Stack

- **React JS**
- **Vite**
- **Tailwind CSS**
- **JavaScript (ES6)**
- **HTML5 & CSS3**

## 🚀 Run Locally

Clone the project

```bash
git clone https://github.com/your-username/cancer-awareness.git
```

Go to the project directory

```bash
cd cancer-awareness
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open in browser

```
http://localhost:5173
```
